# Dependencies for the offline data-ingestion pipeline in scripts/.
#
# These are DELIBERATELY SEPARATE from backend/requirements.txt: the
# backend's requirements are for the running FastAPI service (fastapi,
# sqlalchemy, google-genai, ...); these are one-off/batch tools that
# download, extract, OCR, and normalize source documents offline, and
# never run inside the API process. Install into their own venv:
#
#   cd scripts && python -m venv venv && source venv/bin/activate
#   pip install -r requirements.txt
#
# scripts/run_ocr.py additionally needs system (non-pip) dependencies:
#   apt install tesseract-ocr tesseract-ocr-ara poppler-utils
